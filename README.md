# odin-recipes
Un projet de travail du [Odin Project lessons](https://www.theodinproject.com/).  
Le but du travail est de mettre en avant les connaissances aquises :  
- création d’un répertoire Git et clone sur Github  
- création d’un page _html_ de base avec liens relatifs et absolus  
- utilisation des balises et tags lors des liens vers images  
- commits du répertoire git
